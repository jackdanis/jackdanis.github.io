# jackdanis.github.io

Source for [jackdanis.github.io](https://jackdanis.github.io), Jack Danis's portfolio site. Plain HTML/CSS/JS on GitHub Pages, no build step.

- `css/site.css` and `js/site.js` style and power the main pages. `style.css` is kept only for the older class assignments that still link to it.
- `images/web/` holds compressed WebP copies of the images shown on the site; `images/video/` holds the 3D timelapses as looping MP4s (the original GIFs were 7–92 MB each).
- To add a project, copy one of the `<section class="project">` blocks in `portfolio/` and add a card to `portfolio.html`.
